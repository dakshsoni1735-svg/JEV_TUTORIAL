# Jev Comment Classifier

Jev Comment Classifier is a simple web-based comment moderation system built with **Python Flask, HTML, CSS, and JavaScript**.

It analyzes user comments and classifies them into three categories:

- ✅ **Approved** — Safe content
- 🚩 **Flagged** — Potential spam
- 🚫 **Blocked** — Potentially toxic content

## Features

- Simple and clean web interface
- Comment classification in real time
- Toxic word detection
- Spam word detection
- Safety confidence score
- Dynamic prediction result
- Flask backend with REST API
- No database required
- Beginner-friendly project structure

## Tech Stack

- **Python**
- **Flask**
- **HTML**
- **CSS**
- **JavaScript**
